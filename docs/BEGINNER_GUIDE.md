### Programing Language

#### C
for decompilation(bring back binary to c language) C/C++ Language is important one to learn.
list of stuff you must need know
- **Basic Data Type** : ```char```,```short```,```int```,```float```,```double```,```bool```
- **Derived Data Type** : ```pointer```,```array```,```struct```,```union```,```enum```
- **Modifier Data Type** : ```signed``` it just prefix for antoher data type eg: ```signed int```,```signed short```,etc
							```unsigned``` also prefix for another data type eg: ```unsigned int```,etc
							```long```,
							```long long```
- **Additional Data Type** : this just additional data type/optional
							```int8_t``` - ```int64_t``` number 8 - 64 just stand for size of data type(in bit) by default this stand for ```signed```
							```uint8_t``` - ```uint64_t``` same as previously letter ```U``` just stand for ```unsigned```
